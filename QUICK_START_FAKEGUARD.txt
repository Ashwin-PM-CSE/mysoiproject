5-MINUTE SETUP
================================================================================

Step 1: Install Dependencies
-------------------------------
cd FakeGuard-2.0-COMPLETE/backend
pip install -r requirements.txt

Step 2: Start Backend Server
-------------------------------
python -m uvicorn main:app --reload

Output should show:
    ✓ Vectorizer loaded
    ✓ Model loaded  
    ✓ Uvicorn running on http://0.0.0.0:8000

Step 3: Open Frontend
-------------------------------
Open in your browser:
    FakeGuard-2.0-COMPLETE/fakeguard.html

Step 4: Test Prediction
-------------------------------
1. Paste news text in the form (minimum 20 characters)
2. Click "Analyze Text"
3. See prediction: REAL or FAKE

================================================================================
TROUBLESHOOTING
================================================================================

Problem: Backend won't start
    Solution: pip install -r requirements.txt
    
Problem: ModuleNotFoundError for fastapi
    Solution: pip install fastapi uvicorn scikit-learn

Problem: Frontend shows "Backend unavailable"
    Solution: Ensure backend is running on port 8000
              Check: curl http://localhost:8000/api/health

Problem: Inconsistent predictions
    Solution: Verify same vectorizer file is being used
              Check model files exist in backend/models/
