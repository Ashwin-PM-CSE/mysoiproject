🎯 IF YOU WANT TO...

▶ Run the complete ML + API project:
  1. Navigate to: backend/
  2. Install: pip install -r requirements.txt
  3. Start server: python -m uvicorn main:app --reload
  4. Open: fakeguard.html in browser
  5. Test: Type news → Click "Analyze Text"

▶ Train the ML model from scratch:
  1. Navigate to: backend/
  2. Run: python train_model.py
  3. Models saved to: backend/models/

▶ Use the FastAPI backend only:
  1. cd backend
  2. pip install -r requirements.txt
  3. python -m uvicorn main:app --reload
  4. API available at: http://localhost:8000
  5. Docs: http://localhost:8000/docs

▶ Test the API:
  1. cd backend
  2. python -m pytest test_api.py -v

▶ Run with Docker:
  1. docker-compose up -d
  2. Frontend: http://localhost:3000
  3. Backend API: http://localhost:8000
